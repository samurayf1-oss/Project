# Император: автоматический монитор Python-бота

Это отдельная локальная панель с графиками TradingView Lightweight Charts.
Она показывает фактические записи `paper_trades.csv`, автоматически читая
открытия и закрытия сделок. Это не страница TradingView.com.

## Установка

Распакуй папку `imperator_monitor` из архива **в папку проекта**. Должно получиться:

- `Project/paper_trading.py`
- `Project/paper_trades.csv`
- `Project/settings.py`
- `Project/imperator_monitor/run.py`
- `Project/imperator_monitor/index.html`
- `Project/imperator_monitor/vendor/…`

Нужен Python 3.9 или новее. Дополнительные Python-пакеты, Node.js и npm для
запуска панели не нужны. Библиотека графиков уже входит в архив.
Для свежих котировок нужен доступ к публичному API Bybit.

## Запуск

1. Запускай бота своим обычным способом в первом терминале.
   Для текущего paper-модуля это `python paper_trading.py`.
2. Во втором терминале, из папки проекта, запусти:

   ```powershell
   python .\imperator_monitor\run.py
   ```

3. Браузер откроется автоматически. Адрес: **http://127.0.0.1:8765**.
   Если вкладка не открылась, введи этот адрес вручную.
4. Оставь оба процесса работающими. `Ctrl+C` во втором терминале останавливает
   только панель; бот в первом терминале продолжает работать.

Панель читает журнал каждые **2 секунды** и обновляет котировки каждые
**5 секунд**. Новая сделка появится после того, как бот сохранит её в CSV.
Во время сетевой ошибки котировки и оценка открытого PnL помечаются недоступными;
чтение журнала продолжается независимо от API.

## Как пользоваться

- Выбери инструмент сверху. Свечи идут с Bybit, интервал — **1 час**.
- Стрелки BUY/SELL обозначают входы **из журнала сделок**; кружки — выходы.
  Время маркера привязано к часовой свече, точное время записи есть в карточке.
- Нажми на строку сделки или открытую позицию справа. У открытой позиции
  появятся цена входа и TP/SL из действующих настроек бота.
- При выборе старой закрытой сделки панель запросит свечи около неё.
  Кнопка **«К текущей цене»** возвращает к живому рынку.
- «Следовать за ценой» держит последний бар в поле зрения. Выключи, чтобы
  спокойно изучать выбранный участок.
- Справа отдельно виден последний сигнал `live_signals.csv`. Сигнал HOLD/BUY/SELL
  сам по себе не означает, что бот открыл позицию. Устаревший сигнал отмечается.

## Что означает PnL

Для открытой позиции net оценивается по последней цене Bybit с её собственной
маржой, плечом и ставкой комиссии. Учитываются входная и предполагаемая выходная
комиссии, как в текущем paper-модуле. Это оценка закрытия сейчас, а не подтверждённая
цена исполнения. Проскальзывание и funding дополнительно не моделируются.

Для закрытой позиции показываются **сохранённые** `pnl_usdt` и `pnl_percent`.
Старые записи не пересчитываются задним числом: комиссия и параметры позиции
в них могли отсутствовать. Неизвестные значения обозначаются «—».
Сумма результатов журнала не является процентной доходностью депозита.

Исторические TP/SL текущий CSV не хранит. Поэтому у закрытой сделки показываются
известные цены входа и выхода, а уровни из нынешних настроек не выдаются за исторические.

## Часовой пояс

Текущий бот пишет `datetime.now()` без часового пояса. По умолчанию панель считает
такие записи локальным временем **того же компьютера**, на котором она запущена.
График и таблица отображаются в UTC. Записи с явным UTC-смещением учитываются напрямую.

Если журнал перенесён с другого компьютера или старые записи были сделаны в другом
поясе, можно явно задать смещение для всех дат без пояса:

```powershell
python .\imperator_monitor\run.py --log-offset=+07:00
```

Используй это только если записи действительно сделаны в UTC+7. Для журнала из
нескольких часовых поясов одного общего смещения недостаточно.

## Дополнительные параметры

```powershell
python .\imperator_monitor\run.py --project "C:\путь\к\Project" --port 8766 --no-browser
```

Папка `--project` должна содержать журнал и Python-файлы настроек.
Если порт занят, выбери другой и открой адрес с этим портом.

## Границы панели

Панель только наблюдает: она не импортирует торговые модули, не запускает модель,
не открывает и не закрывает сделки, не изменяет CSV и не использует API-ключи.
Настройки TP/SL читаются как литералы из `settings.py` и `paper_trading.py` без их
выполнения. Параметры сделки берутся из самой записи.

Самостоятельно запущенная панель может получать свежую цену даже при остановленном
боте. Поэтому состояние процесса бота не объявляется «онлайн» по наличию котировок.
Если бот не сохраняет новых сделок, панель их не выдумывает. Обновление CSV также
не подтверждает, что новый сигнал был сформирован: проверь его время справа.

Сервер доступен только на `127.0.0.1`. Он отдаёт только файлы панели и специально
подготовленные данные журнала. `config.py`, ключи и исходники проекта через него
не публикуются. Не меняй привязку на публичный адрес без отдельной защиты.
